## SECURITY DEFINER exécutables par anon (5) — tous STABLE, SQL
abonne_accepte_non_bloque(_auteur)   : auth.uid() NULL → false. Pour un compte : follows(me→auteur,'accepted') AND pas de bloc. Répond sur l'APPELANT (sa propre relation) — pas d'oracle sur autrui.
comment_target_visible(cid)          : cid NULL → true ; post existe → post_is_visible ; commentaire existe → post_is_visible(post) ; sinon TRUE. ⚠ Oracle faible : true/false selon visibilité du post cible, mais révèle aussi "cid existe comme post/commentaire d'un compte privé non suivi" (false) vs "n'existe pas" (true).
post_is_visible(pid)                 : pid NULL ou post inexistant → TRUE ; sinon auteur=me OR auteur non privé OR abonné accepté. ⚠ Oracle : distingue « post d'un compte privé que je ne suis pas » (false) de « post inexistant/public » (true). Un anon peut tester si un id de post appartient à un compte privé. Faible (ids opaques, info = existence).
post_masque(p_id)                    : exists contenus_masques(post, p_id, decision<>'retabli'). ⚠ Oracle : révèle à un anon qu'un post donné est masqué par modération (la table contenus_masques est elle-même fermée). Info de modération exposée à tout appelant.
suppression_de_mon_compte()          : auth.uid() NULL → false ; sinon exists comptes_en_suppression(me). Répond sur l'appelant seulement. Inoffensif.

is_blocked_with(_other)              : bloc dans un sens ou l'autre entre me et _other. Sur l'appelant (révèle qu'on est bloqué PAR autrui — déjà assumé dans la fiche, résidu écrit).
is_conv_member(conv, uid)            : ⚠ ORACLE PUR : exists conv_members(conv, uid) pour N'IMPORTE QUEL uid, N'IMPORTE QUELLE conv. Un compte connecté peut tester l'appartenance d'un tiers à une conversation dont il n'est pas membre (ids evgrp_<event> publics ⇒ liste des membres de la discussion d'un événement reconstituable ; conv 1:1 : ids à deviner). Résidu « connu » depuis le 11/09 (fiche) — toujours vrai le 2026-11-02 — mesuré sous rôle, voir rapport.
is_conversation_creator(conv)        : conversations.created_by = me. Sur l'appelant.
post_auteur_bloque(post)             : exists posts(post) AND is_blocked_with(auteur). ⚠ Oracle : révèle l'EXISTENCE d'un post d'un compte privé (posts fermée) combiné au blocage — faible.
creer_passion(label, emoji[, aliases]) : plpgsql ; session requise ; validations ; pg_advisory_xact_lock ; quota 3/compte (passion_quotas) ; écrit passions. ✓ borné.
creer_et_ajouter_passion             : creer_passion + user_passions(me). ✓
declare_birth_year(y)                : 1900 ≤ y ≤ année courante ; upsert user_safety(me) — ne RECULE jamais majority_at (WHERE … > s.majority_at). ✓
notifier_mentions(genre, ref, [uids]) : session requise ; genre ∈ (commentaire,message) ; ≤ 20 cibles ; EXIGE un commentaire/message RÉCENT (<10 min) de l'appelant sur la cible ; cible doit exister, non bloquée, membre de la conv pour un message ; id déterministe n_m_<md5> ; ON CONFLICT gardé par destinataire. ⚠ Pas de plafond de FRÉQUENCE propre : 20 cibles × N appels/min tant que le commentaire est < 10 min (notifications.trg_rate_limit 60/min par from_id s'applique à l'INSERT côté trigger ? → from_id = moi, OUI le trigger rate_limit_insert('from_id',60) compte les notifications de from_id dans la minute → borne 60/min). Un commentaire sur un post PUBLIC suffit pour mentionner 20 inconnus par appel : spam de mention borné à 60 notifications/min/compte, cible quelconque (pas besoin d'être suivi).
pointer_par_code(event, code)        : session ; event existe ; secret 6 car. alphabet 32 (32^6 ≈ 1,07e9) ; comparaison en clair ; messages distincts ('introuvable','code_incorrect','annulee','hors_fenetre','non_inscrit','deja_pointe','liste_attente','ok'). ⚠ AUCUN plafond d'essais : brute force en théorie possible mais 1e9 combinaisons × latence REST → impraticable dans la fenêtre (date_at-1h → end_at). ⚠ Ordre des contrôles : le code est vérifié AVANT l'inscription → un NON-INSCRIT peut tester des codes (oracle 'code_incorrect' vs 'annulee'/'hors_fenetre'/'non_inscrit' : un non-inscrit qui connaît le bon code apprend que l'événement est annulé/hors fenêtre — négligeable).

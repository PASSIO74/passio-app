## 1. Rôle réel de ce qui a été audité

- **Edge Functions Supabase** (Deno, déployées par `.github/workflows/edge-functions.yml`, fumée OPTIONS 200 / POST sans jeton 401 / `X-Passio-Revision` = SHA) : `ask-ai` (assistant IA, appel Anthropic Haiku), `delete-account` (purge vérifiée sous barrière puis `auth.admin.deleteUser`), `export-account` (portabilité RGPD, instantané SQL), `notify-call` (Web Push : appels — désactivés par `APPELS_ACTIFS=false` — et notifications sociales), `pilotage` (veille pg_cron toutes les 5 min + gestes du compte éditeur). Toute la logique métier vit dans `_shared/*.js`, testée en Node sur le fichier même que Deno déploie.
- **Edge Functions Netlify** : `apercu.js` (liens courts `/p/*`, `/u/*`, `/e/*` : 302 vers le lien profond pour un humain, page OpenGraph sans script pour un robot d'aperçu), `media.js` (cache CDN des médias `/media/<seau>/<chemin>`, Range 206, liste blanche MIME). `cloudflare/passio-cdn-worker.js` est un **vestige** : `PASSIO_CDN_BASE` pointe sur `/media` Netlify, le worker n'est référencé par aucun code vivant.
- **Client** (lecture) : 30 tables via `supa.from(` (profiles 26 sites, conv_members 20, follows 14, event_attendees 14…), 8 RPC (`declare_birth_year`, `rechercher_passions`, `pointer_par_code`, `notifier_mentions`, `irl_interaction_allowed`, `fil_compteurs`, `creer_passion`, `adult_access_status`), 6 invocations d'Edge (`export-account`, `delete-account`, `ask-ai`, `notify-call` ×3), 11 canaux Realtime (`realtime:db`, `user:<me>`, `conv:`, `typing:`, `conv_specific:`, `vlive:`), 2 `fetch` directs vers PostgREST (`user_state` keepalive, `telemetry_events`), Storage : `content` (public) et `attachments` (privé, URL signées 1 h).
- **Environnement** : Deno absent (`index.ts` non exécutés : syntaxe seule, `node --experimental-strip-types --check` OK ×5), Supabase/Netlify injoignables depuis le shell, base de prod lue au canal ① (read-only), API d'avis de sécurité GitHub bloquée pour cette session (registre npm joignable → audit par `npm audit` sur un `package.json` jetable aux versions exactes vendorées).

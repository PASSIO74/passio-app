# Rapports

Sorties **datées** générées par les commandes/skills de pilotage (`/pilot-report`, audits, revues). Convention de nommage : `AAAA-MM-JJ-<type>.md` (ex. `2026-08-08-pilot-report.md`).

Ce dossier est versionné pour garder l'historique des points de situation ; il ne contient jamais de PII ni de secret (les rapports agrègent, ils ne recopient pas de contenu utilisateur).

Prototype · proposition

Écrire dans une conversation

Une conversation 1:1 de bout en bout : arriver sur le dernier message en voyant ce qui relie les deux personnes, écrire dans un champ large, savoir à tout moment si un message est parti, enregistrer un vocal sans le déclencher par erreur, joindre une photo ou sa position en gardant la main, agir sur un message sans geste irréversible.

Tout ce qui est montré existe déjà dans l'application (vocal, pièces jointes, position, réactions, suppression, file hors ligne, proposition IRL) : la proposition réorganise et clarifie, elle n'ajoute pas de fonction.

Maquette interactive : rien n'est envoyé, rien n'est enregistré. Données fictives.

    Flèches ← → : étape précédente / suivante. Le cadre corail désigne l'élément dont parle l'étape. On peut aussi agir librement dans le téléphone : écrire puis envoyer, maintenir le micro (relâcher envoie, glisser à gauche annule), appui long ou clic droit sur une bulle.

Le pilotage ne répond pas

Le téléphone n'arrive pas à joindre le poste de pilotage.

  • Le PC est-il allumé, avec le pilotage lancé ?
  • Le téléphone est-il sur le même Wi-Fi que le PC ?
  • Sur le PC, lance une fois Autoriser-Telephone.cmd (dossier dashboard).
